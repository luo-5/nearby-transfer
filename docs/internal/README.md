# Historical internal records

Files in this directory are retained as non-authoritative development history. They
may describe earlier plans, generated reports, environment-specific experiments, or
claims that are no longer reproducible from the current revision.

Do not use these files as release evidence or current product documentation. Use
[`../capabilities.md`](../capabilities.md), [`../protocol.md`](../protocol.md), the
root README, the current changelog, and automated test output from the exact revision
being evaluated.

Local account names, machine addresses, credentials, device serial numbers, personal
email addresses, and absolute workstation paths must not be added to this directory.
