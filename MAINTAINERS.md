# Maintainers

Nearby Transfer is currently maintained by a small volunteer team.

## Core maintainer

- [`@luo-5`](https://github.com/luo-5) — repository owner, project direction,
  merge decisions, releases, and security coordination.

The Git history includes additional contributors, but contribution count alone does
not grant maintainer, release, or security-advisory access.

## Becoming a maintainer

Maintainer access is granted by the repository owner after a sustained record of
reviewable contributions, respectful collaboration, reliable issue/PR follow-up, and
sound judgment around protocol and security boundaries. Scope may begin with one
package or platform before expanding.

Changes to this file must be reviewed like any other governance change. Application
forms, sponsorship requests, and security-product access must name only people who
actually hold the stated role and permissions.
