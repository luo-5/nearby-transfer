# Support

Nearby Transfer is maintained by volunteers and does not provide guaranteed response
or resolution times.

## Before asking for help

1. Check the [capability matrix](docs/capabilities.md) to confirm the client, platform,
   and protocol path is implemented.
2. Search existing issues and release notes.
3. Reproduce with the newest supported release or `main` when practical.
4. Remove private keys, tokens, filenames, personal data, and unrelated logs.

## Where to ask

- Reproducible bugs: use the bug-report issue template.
- Feature proposals: use the feature-request template and explain the user problem.
- Vulnerabilities: follow [`SECURITY.md`](SECURITY.md); never publish exploit details
  in a normal issue.
- General usage questions: open a clearly labelled issue until a Discussions forum is
  enabled.

Include the Nearby Transfer version/commit, operating system, architecture, selected
client/protocol, exact reproduction steps, expected behavior, and sanitized logs.

Experimental components and unsigned/debug artifacts are supported on a best-effort
basis. Maintainers may ask reporters to reproduce on a currently supported path.
