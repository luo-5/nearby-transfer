传输协议矩阵设置

支持自研极速流、系统原生共享与国际标准存储 7 大主流协议热切换

V2 稳定流

V2 高可靠流式协议

自研 / 稳定推荐
✓ 优势：毫秒级断点续传、分块确认(ACK)防丢包、双向暂停恢复与网络自动重连。
✕ 缺点：带有二进制分帧与 ACK 心跳开销。
★ 适用：跨端日常互传、大文件传输、Wi-Fi 波动弱网环境。
💻 兼容：Nearby Transfer 官方桌面与移动端

Turbo 极速多通道并发协议

4~8路并发 / 千兆极限
✓ 优势：4~8 路并发管道高速分片吞吐，极限压榨 Wi-Fi 6 / 2.5G 千兆局域网硬件带宽。
✕ 缺点：并发占用较多系统 Socket，对老旧弱单核路由器有一定压力。
★ 适用：强信号 5GHz Wi-Fi / 有线千兆内网、传输 5GB+ 4K 电影与超大文件。
💻 兼容：Nearby Transfer Turbo 极速引擎

QUIC / UDP 极速抗弱网协议

UDP / 0-RTT 弱网利器
✓ 优势：基于 UDP 彻底无队头阻塞，丢包率 20%~30% 时仍能维持极高速率，0-RTT 极速握手。
✕ 缺点：部分严格企业/校园网防火墙会限制或阻断 UDP 流量。
★ 适用：弱信号 Wi-Fi 边缘、公共咖啡厅热点、手机移动热点共享。
💻 兼容：Nearby Transfer QUIC 加速引擎

SMB 3.0 局域网网络邻居协议

免装客户端 / 系统原生
✓ 优势：Windows 资源管理器与 macOS Finder 原生直接挂载，无需安装任何 App 即可直接双击打开与编辑。
✕ 缺点：跨网段容易被防火墙拦截 445 端口，协议握手较重。
★ 适用：办公室局域网电脑互访、家庭局域网多设备文件免装客户端直拷。
💻 兼容：Windows 资源管理器、Mac Finder、Linux Samba

WebDAV 直连云盘同步协议

RFC 4918 / 云盘挂载
✓ 优势：基于标准 RFC 4918 协议，支持手机直接挂载电脑磁盘、在线浏览与按需下载点播。
✕ 缺点：散碎小文件浏览时有 XML 元数据解析开销。
★ 适用：手机文件管理器挂载电脑共享库、照片库增量自动备份、在线视频播放。
💻 兼容：Android SAF、Solid Explorer、WPS、Infuse

V1 经典 HTTP 流加密协议

轻量 / 极低开销
✓ 优势：标准 RESTful HTTP 流式传输，防火墙穿透性极好，内存与 CPU 占用极低。
✕ 缺点：不支持细粒度分块断点重续，传输中断需整体重试。
★ 适用：低功耗/低配设备、老旧路由器、散碎小文件与日常照片。
💻 兼容：通用 HTTP 客户端、Web 浏览器、Nearby Transfer v1

FTPS 极速安全传输服务协议

TLS 加密 / 专业工具
✓ 优势：数十年工业级验证的高速传输协议，完美适配第三方专业文件管理工具。
✕ 缺点：主动/被动模式对复杂 NAT 端口映射要求较高。
★ 适用：专业开发者、Linux 终端脚本同步、开发板与 NAS 极速拉取。
💻 兼容：FileZilla、Total Commander、ES 文件浏览器、lftp
